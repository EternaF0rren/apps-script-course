Объекты-словари

Объект — набор подписанных полок: на каждой полке лежит значение, а подпись — ключ. С ним считают по группам, ищут по ID и убирают дубли быстрее и понятнее, чем формулами.

1Ключ и значение

const order = {
  id: 'ORD-1001',
  status: 'In Progress',
  hours: 3.5,
};

order.status          // 'In Progress'
order['hours']        // 3.5 — то же через скобки
order.status = 'Done';   // поменять
order.qc = 5;             // добавить новое поле

// Ключ с пробелом или русский — только в скобках
const counts = {};
counts['In Progress'] = 11;

В фигурных скобках — пары ключ: значение через запятую.

Читать и писать можно через точку order.status или через скобки order['status']. Скобки нужны, когда ключ лежит в переменной или в нём есть пробелы.

Массив — когда важен порядок: «первый, второй, третий». Объект — когда важно имя: «статус», «часы», «D-004».

2Посчитать по группам

const counts = {};

rows.forEach(row => {
  const status = row[4];
  counts[status] = (counts[status] || 0) + 1;
});

// { 'Done': 170, 'In Progress': 11, ... }

Главный шаблон модуля 6. Читается так: «возьми, сколько уже насчитано по этому статусу (или 0, если полки ещё нет), прибавь 1 и положи обратно».

|| 0 нужен потому, что в первый раз полки нет и там undefined.

Это СЧЁТЕСЛИ сразу по всем значениям колонки — одним проходом.

3Карточка со счётчиками

const byWorker = {};

rows.forEach(row => {
  const name = row[6];
  if (!byWorker[name]) {
    byWorker[name] = { orders: 0, hours: 0 };
  }
  byWorker[name].orders++;
  byWorker[name].hours += row[8];
});

// {
//   'Olga L.': { orders: 7, hours: 31.5 },
//   'Gleb G.':  { orders: 5, hours: 22.0 },
// }

На полке может лежать не число, а целая карточка с несколькими счётчиками.

Сначала проверяем, есть ли карточка (if (!byWorker[name])), и создаём пустую. Потом увеличиваем счётчики.

Так за один проход собирается сводная таблица с любыми колонками.

4Из словаря — в таблицу

Object.keys(counts)
// ['Done', 'In Progress', 'Problem', ...]

Object.entries(counts)
// [['Done', 170], ['In Progress', 11], ...]

// Сразу готово для setValues!
const rows = Object.entries(counts);
sheet.getRange(2, 1, rows.length, 2).setValues(rows);

// С карточками — через map
const out = Object.keys(byWorker).sort().map(name =>
  [name, byWorker[name].orders,
   byWorker[name].hours]);

Object.keys — список ключей. Object.entries — список пар «ключ, значение», то есть уже готовые строки для таблицы.

.sort() перед map — чтобы строки шли по алфавиту.

5Справочник вместо ВПР

// Один раз строим справочник: ID → строка сотрудника
const employees = {};
empValues.slice(1).forEach(r => {
  employees[r[0]] = r;
});

// Дальше — мгновенный поиск
employees['D-004']       // вся строка сотрудника
employees['D-004'][5]    // его супервайзер

// Есть ли такой ID?
if (!employees[id]) console.log('No ID: ' + id);

// Только уникальные значения — Set
const ids = new Set(rows.map(r => r[5]));
ids.has('D-004')   // true
ids.size           // сколько разных

Справочник — это ВПР, который строится один раз и потом отвечает мгновенно. Для тысяч строк разница огромная.

Set — набор без повторов. Удобен, когда нужно только «есть / нет» и «сколько разных».

6Частые ошибки

Вместо числа получилось NaN
Прибавили к полке, которой ещё нет: undefined + 1. Нужно (counts[k] || 0) + 1 или проверка if (!obj[k]).
Cannot read properties of undefined (reading 'orders')
Обратились к полю карточки, которую не создали: byWorker[name].orders++ без предварительного byWorker[name] = {…}.
«Done» и «done» посчитались отдельно
Ключи различают регистр и пробелы. Перед подсчётом чистите значения: trim(), единый регистр.
В журнале видно [object Object]
Склеили объект с текстом. Печатайте отдельно: console.log(obj) или JSON.stringify(obj).
