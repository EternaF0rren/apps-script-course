1Матрёшка: от таблицы до ячейки

SpreadsheetAppвход: всё про Таблицы
Spreadsheetфайл таблицы
Sheetлист «Заказы»
Rangeдиапазон A2:L201
valuesсами значения
const ss = SpreadsheetApp.getActive();
const sheet = ss.getSheetByName('Заказы');
const range = sheet.getRange('A2:L201');
const values = range.getValues();

Каждый шаг — «открыть следующую матрёшку». Почти любой скрипт для Таблиц начинается с этих строк.

Главная матрёшка — Range. Красим, читаем, пишем, форматируем — всегда диапазон.

2Таблица и листы

КомандаЧто делает
SpreadsheetApp.getActive()Таблица, к которой привязан скрипт
ss.getSheetByName('Заказы')Лист по имени. Если листа нет — вернёт null
ss.getActiveSheet()Лист, который сейчас открыт у пользователя
ss.getSheets()Список всех листов, чтобы пройти по каждому
ss.insertSheet('Октябрь')Создать новый лист
SpreadsheetApp.openById('ID')Открыть другую таблицу по ID из её ссылки (модуль 6)
ID таблицы — длинный кусок ссылки между /d/ и /edit.

3Как взять диапазон

sheet.getRange('A1')          // одна ячейка
sheet.getRange('A1:L1')       // шапка
sheet.getRange(2, 5)          // строка 2, колонка 5 (E2)

// строка, колонка, сколько строк, сколько колонок
sheet.getRange(2, 1, 10, 3)   // A2:C11

sheet.getDataRange()          // всё, где есть данные
sheet.getLastRow()            // номер последней строки
sheet.getLastColumn()         // номер последней колонки

Буквенный адрес 'A1:L1' удобен, когда диапазон всегда один и тот же.

Числовой getRange(строка, колонка, строк, колонок) — когда размер меняется: «от второй строки до последней».

// Все данные без шапки
sheet.getRange(2, 1,
  sheet.getLastRow() - 1,
  sheet.getLastColumn());

4Читать и записывать

// Одна ячейка
const status = sheet.getRange('E2').getValue();
sheet.getRange('E2').setValue('Готов');

// Много ячеек: двумерный массив [строка][колонка]
const values = sheet.getDataRange().getValues();
values[0][0]   // A1 — первая строка, первая колонка
values[1][4]   // E2

// Записать массив обратно (размер должен совпасть)
sheet.getRange(2, 1, rows.length, 5).setValues(rows);

// Добавить строку в конец
sheet.appendRow(['ORD-10201', new Date(), 'Новый']);

getValue / setValue — для одной ячейки.

getValues / setValues — для диапазона. В сотни раз быстрее, чем ходить по ячейкам по одной.

Внимание к нумерации. В getRange строки и колонки считаются с 1, как в таблице. В массиве values — с 0. Поэтому E2 — это values[1][4].

5Оформить

КомандаЧто делает
.setBackground('#1f2a44')Цвет заливки
.setFontColor('#ffffff')Цвет текста
.setFontWeight('bold')Жирный
.setFontFamily('Arial').setFontSize(10)Шрифт и размер
.setNumberFormat('dd.MM.yyyy')Формат даты или числа ('0.0' — один знак после запятой)
sheet.setFrozenRows(1)Закрепить шапку
sheet.autoResizeColumns(1, 12)Ширина колонок 1–12 по содержимому
.clearContent() / .clearFormat()Стереть значения / оформление
Команды оформления можно писать цепочкой: range.setBackground(...).setFontColor(...).setFontWeight('bold').

6Сказать пользователю

// Всплывающее сообщение в углу таблицы
SpreadsheetApp.getActive().toast('Готово!', 'Скрипт', 5);

// Окно с кнопкой ОК (только при запуске из таблицы)
SpreadsheetApp.getUi().alert('Найдено 12 просрочек');

// Сообщение в журнал выполнения (видит только автор)
console.log('Строк обработано: ' + rows.length);

toast — ненавязчиво: появилось и исчезло через 5 секунд.

alert — требует нажать ОК. Подходит для важного: «Удалить 40 строк?» (подробнее — в модуле 3).

console.log — для отладки. Пользователь его не увидит.

7Частые ошибки

TypeError: Cannot read properties of null (reading 'getRange')
getSheetByName не нашёл лист и вернул null. Проверьте название листа: лишний пробел, другая буква, лист переименовали.
Exception: The number of rows in the data does not match the number of rows in the range
Размер массива в setValues не совпадает с размером диапазона. Берите размер из самого массива: getRange(2, 1, rows.length, rows[0].length).
Exception: The coordinates of the range are outside the dimensions of the sheet
Просим строку 0 или больше строк, чем есть на листе. Помните: в getRange отсчёт с 1.
Скрипт работает, но очень медленно
Внутри цикла стоят getValue или setValue. Прочитайте всё одним getValues, обработайте массив и запишите одним setValues.
