Переменные и типы

Переменная — подписанная коробка, в которую скрипт кладёт значение: имя листа, число заказов, дату. Здесь — как их создавать и какие значения бывают.

← → листать · Home — в начало

1const и let

const sheetName = 'Orders';   // не меняется
let count = 0;                // будет меняться

count = count + 1;            // теперь 1
count += 1;                   // теперь 2

sheetName = 'Archive';          // ошибка!

const — коробка с крышкой на замке. Положили значение один раз, и всё.

let — коробка, в которую можно класть новое значение: счётчики, суммы, «последняя найденная строка».

Правило: по умолчанию пишем const. Меняем на let, только когда значение правда должно меняться.

В старом коде и в записанных макросах встречается var. Он работает как let, но с подвохами. Сами его не пишем.

3Склеиваем текст

const name = 'Olga L.';
const count = 7;

// Через плюс
const a = name + ' has orders: ' + count;

// Через шаблон: обратные кавычки и ${...}
const b = `У ${name} заказов: ${count}`;

// Оба варианта дают:
// У Ольга Л. заказов: 7

Строки можно писать в одинарных '…' или двойных "…" кавычках — разницы нет. Главное, чтобы открывающая и закрывающая совпадали.

Шаблонная строка в обратных кавычках `…` удобнее, когда в текст надо подставить несколько значений: письма, сообщения, заголовки отчётов.

Обратная кавычка на клавиатуре — слева от цифры 1, в английской раскладке.

4Сравниваем значения

status === 'Done'      // равно
status !== 'Done'      // не равно
hours > 8               // больше
hours <= 8              // меньше или равно

'5' === 5               // false: текст ≠ число
Number('5') === 5       // true

// Два условия сразу
status === 'Problem' && hours > 8   // И
status === 'New' || status === 'In Progress'  // ИЛИ

Сравниваем тремя знаками: === и !==. Двойное == пытается «угадать» тип и иногда угадывает не то.

Число из таблицы иногда приходит текстом — например, если в ячейке «3,5». Перед сравнением превратите его в число: Number(...).

&& — «и», || — «или», ! — «не». Как И / ИЛИ / НЕ в формулах таблиц.

5Имена переменных

Так можно

const orders = ...;
const lastRow = ...;
const deadlineHours = 24;
const SHEET_NAME = 'Orders'; // настройка

Так нельзя или не стоит

const last row = ...;  // пробел — ошибка
const 2orders = ...;   // с цифры — ошибка
const x = ...;         // непонятно, что внутри
const заказы = ...;    // работает, но не принято
  • Регистр важен: sheet, Sheet и SHEET — три разные переменные.
  • Слова склеиваем «верблюдом»: lastRow, overdueOrders.
  • Неизменные настройки — большими буквами: HEADER_COLOR.

6Частые ошибки

ReferenceError: orderCount is not defined
Переменной с таким именем нет. Чаще всего — опечатка или другой регистр: объявили orderCount, а пишете ordercount.
TypeError: Assignment to constant variable
Пытаетесь положить новое значение в const. Замените на let, если значение действительно должно меняться.
Вместо суммы получилось «3,52» или NaN
Сложили текст с числом: '3,5' + 2 даёт '3,52'. Сначала превратите текст в число: Number('3,5'.replace(',', '.')).
SyntaxError: Unexpected identifier
Чаще всего — забытая кавычка или скобка в строке выше той, на которую указывает ошибка.
