Условия и циклы

Условие — «если так, сделай это». Цикл — «сделай это для каждой строки». Из этих двух кирпичиков собран почти любой скрипт для таблиц.

1if и else

if (status === 'Problem') {
  sheet.getRange(row, 5).setFontColor('#c62828');
}

if (hours > 8) {
  label = 'Long';
} else {
  label = 'Normal';
}

if (условие) { … } — код в фигурных скобках выполняется, только если условие верно.

else { … } — что делать в противном случае. Необязательная часть.

Как ЕСЛИ в формулах: =ЕСЛИ(I2>8; "Долго"; "Норма") делает то же самое.

2Несколько вариантов

if (hoursLeft < 0) {
  color = 'red';            // просрочен
} else if (hoursLeft < 4) {
  color = 'yellow';         // горит
} else {
  color = 'green';          // время есть
}

// Короткая запись для двух вариантов
const label = hours > 8 ? 'Long' : 'Normal';

else if — следующая проверка, если предыдущая не сработала. Проверки идут сверху вниз, срабатывает первая подходящая.

Короткая запись условие ? если_да : если_нет удобна, когда нужно просто выбрать одно из двух значений.

Вместо вложенных ЕСЛИ на полэкрана — понятная лестница else if. Это одна из главных причин переносить сложные формулы в скрипт.

3Цикл for по строкам

const values = sheet.getDataRange().getValues();

// i = 0 — шапка, поэтому начинаем с 1
for (let i = 1; i < values.length; i++) {
  const row = values[i];
  if (row[4] === 'Problem') {
    console.log('Problem in order ' + row[0]);
  }
}

for (начало; условие; шаг) читается так: «начни с i = 1; пока i меньше числа строк; после каждого круга прибавь 1».

Внутри цикла values[i] — очередная строка таблицы, row[4] — её пятая колонка (E).

Номер строки в таблице = i + 1: массив считается с 0, а таблица — с 1.

4for…of и forEach

// Когда номер строки не нужен
for (const row of values.slice(1)) {
  console.log(row[0]);
}

// То же самое через forEach
values.slice(1).forEach(function (row, i) {
  // i — порядковый номер, начиная с 0
  console.log(i + ': ' + row[0]);
});

// Обойти все листы таблицы
ss.getSheets().forEach(function (sheet) {
  sheet.setFrozenRows(1);
});

for…of и forEach — «для каждого элемента списка». Пишутся короче, чем классический for.

values.slice(1) — все строки, кроме первой (шапки).

Выбирайте любой вариант — все три делают одно и то же. В коде от ИИ встретятся все три.

5Посчитать и отобрать

// Счётчик
let problems = 0;
for (const row of values.slice(1)) {
  if (row[4] === 'Problem') problems++;
}

// То же через filter: «оставь только подходящие»
const open = values.slice(1).filter(function (row) {
  return row[4] !== 'Done';
});
console.log('Open: ' + open.length);

// Сумма часов
let total = 0;
values.slice(1).forEach(function (row) {
  total += row[8];
});

Три самых частых шаблона: посчитать (счётчик ++), отобрать (filter), сложить (+=).

problems++ — прибавить 1. total += row[8] — прибавить значение из колонки I.

Это аналоги СЧЁТЕСЛИ, ФИЛЬТР и СУММЕСЛИ — только с любыми условиями, какие придумаете.

6Частые ошибки

if (status = 'Done')
Одно = — это присваивание, а не сравнение. Условие всегда окажется верным. Сравниваем тремя знаками: ===.
Цикл обрабатывает шапку как данные
Начали с i = 0 или забыли slice(1). Шапка — строка 0 массива.
TypeError: Cannot read properties of undefined
Условие i <= values.length вместо i < values.length: на последнем круге строки с таким номером нет.
Скрипт работает минуты и падает по времени
Внутри цикла стоят getValue / setValue. Читаем всё до цикла, пишем всё после цикла.
