Функции

Функция — именованный набор действий. Одни функции запускает человек из меню, другие — сами скрипты как помощников. Здесь — как их писать и не путаться.

← → листать · Home — в начало

1Объявить и вызвать

// Объявляем
function sayHello() {
  SpreadsheetApp.getActive().toast('Hello!');
}

// Вызываем из другой функции — со скобками
function main() {
  sayHello();
}

function имя() { … } — объявление. Код внутри не выполняется, пока функцию не вызовут.

имя() — вызов. Скобки обязательны: без них функция не запустится.

Из меню и кнопок функцию назначают по имени без скобок: addItem('Hello', 'sayHello').

2Параметры и return

// hours — параметр: значение снаружи
function hoursToText(hours) {
  const h = Math.floor(hours);
  const m = Math.round((hours - h) * 60);
  return h + ' h ' + m + ' min';
}

hoursToText(2.25)   // '2 h 15 min'
hoursToText(0.5)    // '0 h 30 min'

// Несколько параметров — через запятую
function isLate(deadline, done) {
  return done > deadline;
}

Параметры — то, что функция получает на вход. return — то, что она отдаёт обратно.

Как формула в таблице: =ОКРУГЛ(A1; 2) получает число и точность и возвращает результат.

return сразу завершает функцию. Всё, что ниже него, не выполнится.

4Короткая запись: стрелочные функции

// Обычная запись
const open = values.filter(function (row) {
  return row[4] !== 'Done';
});

// Стрелочная — то же самое
const open2 = values.filter(r => r[4] !== 'Done');

// Стрелочная с несколькими строками
const ids = values.map(row => {
  const id = row[0];
  return id.toUpperCase();
});

Стрелка => — короткий способ написать функцию «на один раз», чаще всего внутри filter, map, forEach.

Если тело в одну строку и без фигурных скобок, return подставляется сам.

ИИ часто пишет стрелками. Читайте row => … как «для каждой строки row верни …».

5Что видно внутри и снаружи

const SHEET = 'Orders';  // видна всем функциям

function countOrders() {
  const sheet = getSheet(SHEET); // только здесь
  return sheet.getLastRow() - 1;
}

function report() {
  console.log(countOrders());  // 200
  console.log(sheet);  // sheet is not defined
}

Переменная, объявленная внутри функции, живёт только в ней. Другие функции её не видят.

Константы вне функций (как в Config.gs) видны во всём проекте, во всех файлах.

Нужно передать значение из одной функции в другую — передавайте параметром или через return.

6Частые ошибки

Функция вернула undefined
Забыли return. Функция всё посчитала, но ничего не отдала обратно.
TypeError: Cannot read properties of undefined (reading 'range')
Запустили onEdit(e) из редактора. Объект e приходит только при настоящей правке в таблице — проверяйте, редактируя ячейку.
TypeError: … is not a function
Вызвали как функцию то, что ею не является: опечатка в имени или скобки после переменной.
Script function not found
В меню или на кнопке указано имя функции, которой нет в проекте, или имя со скобками: 'sayHello()' вместо 'sayHello'.
