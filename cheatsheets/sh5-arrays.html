Массивы

Массив — список значений. Всё, что скрипт читает из таблицы через getValues, приходит массивом строк, а каждая строка — массив ячеек. Научитесь ходить по этим спискам — и любая обработка данных станет быстрой.

← → листать · Home — в начало

1Список в квадратных скобках

const statuses = ['New', 'In Progress', 'Done'];

statuses[0]        // 'New' — счёт с нуля!
statuses[2]        // 'Done'
statuses.length    // 3 — сколько элементов
statuses.at(-1)    // 'Done' — последний

statuses.push('Problem');   // добавить в конец
statuses.length    // 4

Элементы считаются с нуля: первый — [0], второй — [1].

length — сколько элементов. Последний элемент — [length - 1] или at(-1).

В таблице строки и колонки считаются с 1, в массиве — с 0. Это главный источник путаницы. Держите в голове: «в массиве на один меньше».

2Таблица — это массив массивов

const values = sheet.getRange('A1:C3').getValues();
// [
//   ['ID',       'Created', 'Deadline'],  ← [0]
//   ['ORD-1001', дата,     дата],       ← [1]
//   ['ORD-1002', дата,     дата],       ← [2]
// ]

values[1][0]     // 'ORD-1001' — строка 2, колонка A
values.length    // 3 — строк
values[0].length // 3 — колонок

Первая скобка — номер строки, вторая — номер колонки. Оба с нуля.

ЯчейкаВ массиве
A1values[0][0]
E2values[1][4]
Строка N, колонка Mvalues[N-1][M-1]

3Одна колонка — тоже двумерная

// Колонка I (часы) из трёх строк
sheet.getRange('I2:I4').getValues()
// [[3.5], [4.0], [2.2]]  — не [3.5, 4.0, 2.2]!

// Сделать плоский список
const hours = sheet.getRange('I2:I4').getValues()
  .map(row => row[0]);           // [3.5, 4.0, 2.2]

// Обратно для записи — каждое число в свои скобки
sheet.getRange('P2:P4')
  .setValues(hours.map(h => [h * 2]));

getValues всегда возвращает массив строк — даже если колонка одна.

И setValues всегда ждёт массив строк. Плоский список [1, 2, 3] он не примет.

map(row => row[0]) — «разверни в плоский список». map(x => [x]) — «заверни обратно».

4map, filter, find, some

МетодЧто делаетПример
forEachСделать что-то для каждого элементаrows.forEach(r => console.log(r[0]))
mapПревратить каждый элемент в новыйrows.map(r => r[0]) — список ID
filterОставить подходящиеrows.filter(r => r[4] === 'Problem')
findНайти первый подходящийrows.find(r => r[0] === 'ORD-1001')
someЕсть ли хоть один подходящийrows.some(r => r[8] > 24) → true/false
includesЕсть ли значение в списке['Done','Problem'].includes(status)
Методы можно соединять цепочкой: rows.filter(…).map(…) — «отбери, потом преврати».

5Срезать, склеить, отсортировать

values.slice(1)          // все строки, кроме шапки
values.slice(0, 10)      // первые 10 строк

[1, 2].concat([3, 4])    // [1, 2, 3, 4]
['ID'].concat(row)       // добавить колонку слева

// Сортировка текста — сразу работает
names.sort();

// Сортировка чисел — нужна функция сравнения!
[10, 9, 100].sort()                // [10, 100, 9] ✗
[10, 9, 100].sort((a, b) => a - b) // [9, 10, 100] ✓

// Строки таблицы по часам, по убыванию
rows.sort((a, b) => b[8] - a[8]);

slice не меняет исходный массив, а возвращает новый. Удобно, чтобы отрезать шапку.

sort без аргументов сравнивает всё как текст. Для чисел и дат пишите функцию: (a, b) => a - b — по возрастанию, b - a — по убыванию.

6Частые ошибки

The parameters (number[]) don't match the method signature for SpreadsheetApp.Range.setValues
В setValues передали плоский список. Заверните каждый элемент: list.map(x => [x]).
Сравнение values[i] === 'Done' всегда false
Сравнили целую строку с текстом. Нужна ячейка: values[i][4] === 'Done'.
Числа отсортировались странно: 10, 100, 9
Забыли функцию сравнения в sort.
Шапка попала в расчёт
Забыли slice(1), и строка с названиями колонок посчиталась как данные.
