Даты и строки

Дедлайны, просрочки, «Отчёт 10.2026», имена с лишними пробелами — почти каждый скрипт работает с датами и текстом. Здесь — как считать, сравнивать и красиво выводить.

← → листать · Home — в начало

1Откуда берутся даты

// Из ячейки с датой — сразу объект Date
const deadline = values[1][2];
deadline instanceof Date     // true

// Сейчас
const now = new Date();

// Год, МЕСЯЦ С НУЛЯ, день, часы, минуты
new Date(2026, 9, 19)        // 19 октября 2026!
new Date(2026, 9, 19, 14, 30)

// Из текста — только в формате ГГГГ-ММ-ДД
new Date('2026-10-19')       // работает
new Date('19.10.2026')       // Invalid Date

Если в ячейке настоящая дата, getValues вернёт объект Date. Если дата набрана текстом — вернётся строка, и её надо разобрать (функция parseDate из модуля 2).

Месяцы в JavaScript считаются с нуля: январь — 0, октябрь — 9, декабрь — 11. Дни — как обычно, с 1.

2Считать с датами

const HOUR = 60 * 60 * 1000;   // мс в часе
const DAY = 24 * HOUR;          // мс в дне

// Сравнивать можно напрямую
if (deadline < now) { /* просрочен */ }

// Разница — в миллисекундах
const hoursLeft = (deadline - now) / HOUR;
const daysLate = Math.floor((done - deadline) / DAY);

// Прибавить время
const in3days = new Date(now.getTime() + 3 * DAY);
const in4hours = new Date(now.getTime() + 4 * HOUR);

Внутри дата — это число миллисекунд. Поэтому даты можно сравнивать знаками < и > и вычитать друг из друга.

Результат вычитания делим на «миллисекунд в часе» или «в дне» — получаем часы или дни.

Заведите константы HOUR и DAY — код станет читаться как текст: «3 * DAY».

3Дата → красивый текст

const tz = SpreadsheetApp.getActive()
  .getSpreadsheetTimeZone();

Utilities.formatDate(now, tz, 'dd.MM.yyyy')
// → 19.10.2026
Utilities.formatDate(now, tz, 'dd.MM.yyyy HH:mm')
// → 19.10.2026 14:30
Utilities.formatDate(now, tz, 'MM.yyyy')
// → 10.2026
Utilities.formatDate(now, tz, 'yyyy-MM-dd')
// → 2026-10-19
КодЧто это
ddдень: 01–31
MMмесяц: 01–12
yyyyгод: 2026
HHчасы: 00–23
mmминуты: 00–59
MM — месяц, mm — минуты. Перепутать их — самая частая ошибка в форматах дат.

5Строки: чистка и поиск

'  Olga L. '.trim()           // 'Olga L.'
'DONE'.toLowerCase()          // 'done'
'ord-1001'.toUpperCase()      // 'ORD-1001'

'More photos needed'.includes('photos')   // true
'ORD-1001'.startsWith('ORD')         // true

'Ivanova Anna'.split(' ')     // ['Ivanova', 'Anna']
'3,5'.replace(',', '.')       // '3.5'
'a-b-c'.replaceAll('-', '')   // 'abc'

String(7).padStart(3, '0')    // '007' — для ID
'Order'.length                // 5

Методы строк не меняют исходный текст, а возвращают новый. Результат нужно сохранить: name = name.trim().

replace меняет только первое вхождение, replaceAll — все.

Перед сравнением текстов чистите оба: a.trim().toLowerCase() === b.trim().toLowerCase().

6Частые ошибки

Отчёт за ноябрь вместо октября
new Date(2026, 10, 1) — это 1 ноября: месяц считается с нуля.
В названии листа «Отчёт 30.2026»
В формате написали mm (минуты) вместо MM (месяц).
Даты в письме сдвинуты на несколько часов
В formatDate указан не тот часовой пояс, или пояс проекта не совпадает с поясом таблицы.
deadline < now всегда false
В ячейке дата набрана текстом, и сравнивается строка с датой. Проверьте: deadline instanceof Date.
