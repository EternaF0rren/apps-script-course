# Шаблон запроса к ИИ для скрипта Google Таблиц

Скопируйте шаблон, заполните поля в квадратных скобках и отправьте ИИ-ассистенту,
которым разрешено пользоваться в компании. Реальные данные не вставляем: только
названия колонок и 2–3 строки-примера с вымышленными значениями.

```
Напиши функцию Google Apps Script для таблицы Google Sheets.

Где данные: лист «[имя листа]», шапка в строке 1, данные со строки 2.
Колонки: A — [название], B — [название], C — [название], ...
Пример строк (вымышленные данные):
[ORD-1 | 20.08.2026 10:00 | В работе | D-004]
[ORD-2 | 21.08.2026 15:30 | Готов   | D-011]

Что сделать: [опишите результат словами, как коллеге].
Куда вывести результат: [тот же лист / новый лист «...» / сообщение / письмо].
Как запускать: [из меню / кнопкой / каждое утро по расписанию / при правке].

Ограничения:
- читай и записывай данные целиком через getValues/setValues, не по одной ячейке;
- ничего не удаляй без подтверждения пользователя;
- не отправляй данные никуда, кроме [указать, если нужно];
- добавь комментарии на русском к каждому шагу;
- если чего-то не хватает для решения, сначала задай мне вопросы.
```

## Если код не заработал

Отправьте ИИ три вещи: код, который вы запускали, точный текст ошибки из журнала
выполнения и номер строки. Фраза «не работает» без ошибки почти никогда не помогает.
