# Скрипты для Google Таблиц

Материалы курса по Google Apps Script для сотрудников ADP (Admin Development Program).
Курс учит находить в своей работе рутину, которую можно отдать скрипту, и автоматизировать её:
от форматирования и кнопок до автоотчётов со статистикой и графиками.

**Сайт курса:** https://&lt;github-логин&gt;.github.io/apps-script-course/

## Что здесь лежит

- HTML-презентации модулей и шпаргалки по синтаксису JavaScript. Сайт публикуется через GitHub Pages.
- Библиотека учебных скриптов (`.gs`), разложенная по модулям.

Тексты модулей лежат в Google Docs, тесты — на учебной платформе. В репозитории их нет.

## Структура

```
index.html            — главная страница: карточки модулей и шпаргалок
modules/              — презентации модулей 0–8
cheatsheets/          — шпаргалки Ш1–Ш7 по синтаксису
scripts/              — учебные скрипты, папка на каждый модуль
assets/               — стили и скрипты страниц, песочница sandbox.xlsx
tools/                — генератор песочницы (build_sandbox.py)
```

## Правила

- Сайт публичный. В презентациях и скриптах используются только обезличенные данные: никаких реальных имён, email, ставок и ссылок на рабочие таблицы.
- Скрипты из `scripts/` проверяются на копии учебной таблицы, а не на рабочих данных.
- Сначала публикуется русская версия, английская появится после пилота.

## Публикация

Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
Изменения появляются на сайте через 1–2 минуты после коммита в `main`.
